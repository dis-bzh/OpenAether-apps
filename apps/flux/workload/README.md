# workload — default profile of client/spoke clusters

`kustomization.yaml` is **generated** by the picker (do not edit by hand):

```bash
python3 scripts/pick.py vault eso certs gateway cnpg storage observability identity kyverno metrics -o apps/flux/workload
```

Security baseline + OpenBao + ESO + PKI + gateway + CNPG + storage +
observability + identity (Zitadel) + Kyverno + metrics-server (+ backup bricks
as companions). No CAPI: a spoke does not need it.

- A workload cluster provisioned by **the infra** (tofu): Flux points here via
  `apps/flux/${cluster_role}` (bootstrap-manifests).
- A **CAPI** child cluster: profile selected by `${CHILD_PROFILE}`
  (see `apps/clusters/README.md`) — either `workload` or a dedicated profile
  generated by the picker (e.g. `apps/flux/workload-edge-1`).
